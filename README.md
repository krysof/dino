# Dino Pure Native C++ / WebAssembly

**在线运行：** https://krysof.github.io/dino/

这个仓库只承载 GitHub Pages 的编译后二进制产物，不公开游戏主程序的 C++、汇编、
反编译源码或生成脚本。页面无需选择或上传 ROM。

## 发布物

- `site/dino.wasm`：逆向生成的 C++ 主程序和原生视频、内存、输入运行时；
- `site/dino.data`：按已证明布局转换的图形、QSound 和主程序数据 `.bin` 数组包；
- `site/dino.js`：Emscripten 浏览器装载胶水；
- `site/mobile-game-shell.js`：响应式横屏/竖屏降级与多点触控输入层；
- `site/index.html`：Canvas/WebAudio、键盘、手柄和触摸前端。

主 CPU、视频、VBlank、内存和输入都不依赖 CPS/libretro/68000 模拟器。唯一允许的模拟
边界是 Z80/QSound 音频。构建审计拒绝 C/C++、汇编、Python 源文件、ROM 压缩包以及
libretro/CPS 执行核心符号；已验证主程序可执行 C++ 覆盖率为 100%。

当前发行版包含扩展简体中文汉化：527 条精确规则覆盖投币/开始、人物姓名和能力、
全部 41 个 HUD 敌人/Boss 名称、八章标题、关卡地点、开场叙事、过场对白、Boss 台词与
结局文本，并补齐三地区开机警告、授权页、道具和武器标签。608 个中文字形已经转换成
1 bpp 二进制数组并封装在 `dino.data` 中。程序表内 318 条大字体物理行、41 个 HUD
名称、17 条警告行、7 条授权行、17 个道具标签和 15 个武器标签均通过自动完整性审计；
20,000 帧演示循环与 10,000 帧自动游戏的可见英文审计结果均为 0。原版 8×8 英文字块
命中后统一以完整 16×16 中文字形替换，不再缩成难辨认的小字。人物选择卡片改为三行
紧凑排版；战斗 HUD 另外识别无后缀玩家短名，下移血条；玩家头像补足 8 像素，敌方头像
则补到与玩家一致的 32 像素高并整体下移 8 像素；玩家名与敌人名均下移 8 像素。拾取物品
会把两行 8×8 原文合成一行 16×16“数值名称 分”（如 `1000千元 分`），持枪和武器名称
上移 8 像素，避免姓名、头像和血条重叠。网页开场和游戏
标题画面均显示 `http://www.ff18.com　白河愁`。游戏 Logo、
CAPCOM、人物插画装饰字和 `1P/2P/3P` 等直接画进图形资源的美术文字仍保留原样。

移动端首次开始只尝试全屏，不锁定设备方向。手机竖屏时游戏仍以未旋转的横向 12:7
contain 画面显示，Canvas 内部分辨率固定为 384×224。虚拟摇杆支持
八方向、快速轻触、长按、多点方向+动作，并在取消、失焦和切后台时立即释放，不会卡键。
摇杆尺寸按较短视口边自适应计算并设置上下限，控制区会随之自动预留空间。攻击和跳跃
在 160 ms 内分别按下时会重整为同一个采样边沿，动作按钮也带有轻微滑出迟滞，方便可靠
触发原作的攻击+跳跃组合技。

键盘采用 MAME 标准街机默认布局：1P 为方向键、左 `Ctrl`/左 `Alt`、`5` 投币、`1`
开始；2P 为 `R/F/D/G`、`A/S`、`6`、`2`；3P 为 `I/K/J/L`、右 `Ctrl`/右
`Shift`、`7`、`3`。开始画面会在桌面设备上直接显示这张按键表。
`P` 用于暂停/继续，暂停时会释放按住输入并停止游戏帧和声音；切后台自动暂停不会覆盖
手动暂停状态。

Web 主循环固定为原机 59.63 Hz，不会随 120/144 Hz 显示器刷新率倍速运行。点击开始会
同步请求游戏根元素全屏；若浏览器策略拒绝，桌面右上角会出现可重试的全屏按钮。

本版修正了动态函数表遗漏和主 CPU 帧调度失控：补全实际玩法发现的嵌套 pointer/offset
分发表目标，保持 68000 统一只读常量地址空间，并把每帧主 CPU 限定为原机周期预算。发布前
已通过 5,000 帧纯 C++ 游戏测试、1,200 帧参考 CPU 差分以及桌面/移动浏览器自动回归。
